AI-Radio Backend Server

RTL-SDR Interface with AI-Powered Anomaly Detection

Server Status

Backend server is running and ready to accept connections.

Frontend should be running on http://localhost:3000

API Endpoints

  • GET /api/devices - List available RTL-SDR devices
  • POST /api/devices/{id}/connect - Connect to device
  • POST /api/devices/{id}/disconnect - Disconnect from device
  • GET/POST /api/settings - Get/update SDR settings
  • POST /api/stream/start - Start spectrum streaming
  • POST /api/stream/stop - Stop spectrum streaming
  • GET /api/spectrum - Get single spectrum reading

WebSocket Events

  • spectrum_data - Real-time spectrum data
  • waterfall_data - Waterfall display data
  • status - Connection status updates
